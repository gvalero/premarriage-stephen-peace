# Stephen & Peace - Preparing for Intimacy Homework

GitHub Pages-ready homework for Session 6.

The homework follows the 17 August 2026 discussion and includes:

1. Reading the course book's `Preparing for Intimacy` chapter (pp. 68-73).
2. Separate reflection on expectations, hopes and concerns.
3. A private couple conversation about the wedding night, consent, preferences and boundaries.
4. A concrete physical-boundary plan for the remaining time before the wedding.
5. Health, contraception and children follow-up.
6. Personal actions raised during the meeting.
7. Reflection questions for the final course session on 31 August.

Privacy design:

- Explicit sexual preferences remain private between the couple.
- The submitted form captures only agreements, non-explicit questions and practical actions.
- The static page stores answers in the browser only and does not upload them.

The chapter PDF is included as `reading-preparing-for-intimacy-pp-68-73.pdf`.
